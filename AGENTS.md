# Agent instructions

This repository edits short vertical videos for the TikTok account «Пантеон литература».

- General editing rules (fonts, colours, safe areas, CTA zone): `CLAUDE.md`. They apply to every agent.
- To finish-edit a video with graphics, animation and sound effects ("домонтируй", "добавь визуал и звуки", "сделай как прошлые"), follow the skill in `skills/tiktok-montage/SKILL.md`. It contains the workflow, the style guide, the JSON edit-plan format, the render engine and an approved example plan.
- Never commit video or audio files (see `.gitignore`).
